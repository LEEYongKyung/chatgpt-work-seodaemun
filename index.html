실제 작업 시작 화면

목표 + 자료 + 저장 위치

캡처의 프로젝트 이름과 도구는 실제 사전 실행 사례입니다. ‘나 대신 승인’ 표시는 이 실행의 선택 상태이며, 모든 작업의 승인 정책을 뜻하지 않습니다.

화면 자료 안내 Work 전환·폴더 연결·권한 설정의 개별 캡처는 아직 확보되지 않았습니다. 위 항목은 준비 안내로 표시했습니다.

04 / 실제 사전 실행으로 보는 10분 시연

연간 전체 자료나 재실행의 보장 수치가 아닙니다. 임시자료·누락·분석 기준을 결과에서 확인하세요.

담당자의 확인

시연 요청문

원본과 공개 본문 사본, 왜 구분했을까요?
제공된 실행 기록에서는 임시회의록 다운로드 제한 6건과 첨부 원본 없음 1건을 공개 본문 TXT·HTML 사본으로 보존했습니다. 원본 다운로드와 사본 보존은 구분하며, 다운로드 제한을 우회하는 방식으로 설명하지 않습니다.
분석 엑셀에서 무엇을 검토하나요?
‘의원별 요약’, ‘지적사항 상세’, ‘자료범위·분석기준’의 세 시트를 확인합니다. 날짜·발언자·원문 발췌를 대조하고, 의혹과 확정 사실, 집행부의 검토 약속과 실제 완료를 구분합니다. 본문에 없는 서면질문은 제외된 범위로 확인합니다.
강의에서는 31분의 생성 시간을 어떻게 보여주나요?
캡처에는 약 31분의 분석 작업이 나타납니다. 강의는 실제 요청·진행 화면과 사전에 생성한 결과를 이어 보여줍니다. 실시간으로 10분 만에 완료한 사례로 소개하지 않습니다.

GitHub Pages용 정적 강의 웹페이지. 빌드나 로그인, API 키가 필요하지 않습니다.

## 미리보기

이 폴더를 정적 HTTP 서버로 열어 index.html을 확인합니다. 파일을 직접 열어도 내용을 볼 수 있지만 클립보드 동작은 브라우저 환경에 따라 제한될 수 있습니다.

## GitHub Pages 업로드

index.html, styles.css, app.js, assets 폴더를 저장소의 게시 경로에 그대로 올립니다. 저장소 루트 또는 docs 폴더를 Pages 게시 경로로 지정할 수 있습니다. 이 작업에서는 게시하지 않았습니다.

## 구성

3D CSS 도식 / 개념 비교 / 기능 / 시작·설정 안내 / 실제 회의록 시연 5단계 / 활용 사례 6개 / 검토 기준 / 참고 링크.

캡처 9장은 사용자 제공 화면에서 업무와 무관한 영역을 잘라 저장했습니다. 원본은 포함하지 않습니다. 별도 설정 캡처가 없는 부분은 준비 안내로 명시했습니다.

애니메이션 끄기 버튼과 시스템의 움직임 줄이기 설정을 지원합니다. 3D 도식은 개념 설명용이며 실제 앱 화면은 캡처로 구분했습니다.

구의회 실행 수치는 제공된 기록의 기준일·범위에 한정됩니다. 요약보고서 생성은 포함하지 않습니다. 활용 사례는 참고 자료를 행정 업무로 재구성한 교육용 제안입니다.

Google Fonts는 선택적 외부 자원입니다. 네트워크가 차단되면 기본 sans-serif 글꼴로 표시합니다. 캡처·스타일·동작 파일은 이 폴더에 포함합니다.
